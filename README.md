# Projeto de Músicas e Podcasts em Java

Projeto desenvolvido em Java com foco no aprendizado de **Programação Orientada a Objetos (POO)**, utilizando classes e objetos para representar músicas, podcasts e conteúdos favoritos.

A aplicação demonstra a criação e manipulação de diferentes tipos de conteúdo, permitindo definir suas informações, registrar reproduções e curtidas e adicionar os conteúdos à lista de favoritos.

## Funcionalidades

- **Cadastro de informações:** definição de título, número de reproduções, curtidas e atributos específicos de músicas e podcasts.
- **Exibição de informações:** apresentação dos dados dos conteúdos por meio de métodos próprios.
- **Registro de reproduções:** utilização de métodos para contabilizar as reproduções.
- **Registro de curtidas:** utilização de métodos para contabilizar as curtidas dos conteúdos.
- **Conteúdos favoritos:** inclusão de músicas e podcasts na estrutura de favoritos.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- Métodos getters e setters
- Estruturas de repetição (`for`)
- Entrada e saída de informações pelo console

## Organização do projeto

O projeto utiliza classes separadas para representar os diferentes elementos da aplicação:

- `Principal`: classe responsável pela execução do programa e pela criação e configuração dos objetos.
- `Musica`: representa uma música e suas informações, como cantor, álbum e gênero.
- `Podcast`: representa um podcast e suas informações, como apresentador e descrição.
- `MinhasPreferidas`: utilizada para incluir músicas e podcasts entre os conteúdos favoritos.

## Demonstração

Na execução principal, o programa:

1. Cria um objeto de música e define suas informações.
2. Exibe os dados da música e a adiciona aos favoritos.
3. Cria um objeto de podcast e define suas informações.
4. Exibe os dados do podcast e o adiciona aos favoritos.
5. Simula novas reproduções e curtidas para os dois conteúdos.

Os exemplos utilizados são a música *Talvez você precise de mim*, do cantor Veigh, e o podcast Podpah, apresentado por Igão.

## Objetivo do projeto

Praticar os fundamentos da Programação Orientada a Objetos em Java, desenvolvendo a capacidade de modelar elementos do mundo real por meio de classes e objetos, organizar responsabilidades e trabalhar com métodos para manipular informações.

## Aprendizados

Este projeto faz parte da minha jornada de aprendizado em Java e contribui para o desenvolvimento de conhecimentos em:

- Modelagem de classes e criação de objetos;
- Encapsulamento e manipulação de atributos;
- Organização do código em diferentes classes e pacotes;
- Reutilização de métodos;
- Estruturas de repetição aplicadas à manipulação de dados.
